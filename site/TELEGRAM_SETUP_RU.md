# Как открыть TOO HUNGRY на телефоне — в Telegram или браузере

Инструкция рассчитана на запуск игры по ссылке внутри Telegram. Командная строка, отдельный сервер и программирование бота для этого не нужны.

## Перед публикацией

Публичный GitHub Pages-адрес откроет всем желающим файлы игры, фотографию шефа и пять треков альбома. Владелец игры разрешил публичный выпуск 2026-11-09; пока GitHub Actions не завершит публикацию, адрес Mini App указывать рано.

## 1. Включить GitHub Pages

1. Открой репозиторий `TOO-HUNGRY-THE-LAST-DROP` на GitHub.
2. Перейди в **Settings → Pages**.
3. В разделе **Build and deployment** выбери источник **GitHub Actions**.
4. Открой вкладку **Actions** и выбери workflow **Publish TOO HUNGRY Mini App**.
5. После включения Pages каждый push в `master` сам запускает публикацию папки `dist/`.
6. Чтобы опубликовать текущую версию сразу, открой **Actions → Publish TOO HUNGRY Mini App → Run workflow** и оставь `confirm_public_release` включённым. Владелец уже разрешил публичный выпуск; флажок подтверждает настройку ручного workflow.
7. Дождись зелёного завершения запуска. В деталях публикации появится рабочий адрес; он будет вида `https://xxxarizma19-tech.github.io/TOO-HUNGRY-THE-LAST-DROP/`.
8. Открой этот адрес обычным браузером телефона и убедись, что стартовый экран загрузился.

После первого включения источника Pages новые коммиты в `master` автоматически публикуют игру; ручной запуск остаётся доступен на вкладке Actions.

## 2. Создать своего бота

1. В Telegram найди официальный **@BotFather** и открой чат.
2. Отправь `/newbot`.
3. Введи отображаемое имя `TOO HUNGRY`.
4. Придумай уникальное имя пользователя бота, которое заканчивается на `bot`.
5. Сохрани выданный BotFather токен у себя в надёжном месте. Для простой игры-витрины он не вставляется в сайт и не нужен для настройки ссылки. Никому не отправляй токен и не публикуй его в репозитории.

## 3. Привязать игру к боту

Лучший вариант — основное приложение бота с кнопкой запуска в его профиле:

1. В чате с @BotFather отправь `/mybots` и выбери созданного бота.
2. Открой настройку **Main Mini App** (в меню Bot Settings / Configure Mini App) и включи её.
3. Вставь HTTPS-адрес, который GitHub Pages показал после успешной публикации.
4. Сохрани настройки. У профиля бота появится кнопка открытия приложения.

Чтобы также показывать кнопку игры в поле ввода чата, в @BotFather отправь `/setmenubutton`, выбери бота, задай подпись `Играть` и укажи тот же HTTPS-адрес. Главное приложение и кнопка меню — два способа открыть одну и ту же игру.

## 4. Открыть на телефоне

1. Открой чат со своим ботом в Telegram на телефоне.
2. Нажми **Играть** или кнопку запуска приложения в профиле.
3. Разреши Telegram перевести окно в альбомный режим; на экране игры нажми **НАЧАТЬ ЗАБЕГ**.
4. Если первое открытие зависло на старой версии, закрой Mini App целиком, снова открой чат и запусти игру ещё раз.

Прогресс кампании хранится отдельно на каждом устройстве или в каждом приложении. Чтобы перенести его между Telegram и обычным браузером, на стартовом экране нажми **СКАЧАТЬ СОХРАНЕНИЕ**, перенеси файл на нужное устройство, затем выбери **ЗАГРУЗИТЬ ФАЙЛ** и подтверди импорт. Для игры на компьютере можно открыть тот же HTTPS-адрес в браузере.

## 5. Добавить браузерную игру на главный экран

Это необязательно: после установки публичной HTTPS-страницы игру можно запускать отдельной иконкой и вне Telegram.

- **Android, Chrome:** открой адрес игры → меню `⋮` → **Установить и создать ярлык** → **Установить**.
- **iPhone, Safari:** открой адрес игры → **Поделиться** → **На экран «Домой»** → **Добавить**. Если пункт не виден, прокрути список действий или включи его через **Изменить действия**.

На iPhone Safari можно также включить **Открывать как веб-приложение**, чтобы сайт запускался отдельно от браузера. Названия пунктов могут немного отличаться в зависимости от версии телефона.

## Если не открывается

- Убедись, что запуск GitHub Actions завершился зелёным статусом и адрес начинается с `https://`.
- Проверь, что в BotFather указан полный адрес с путём `/TOO-HUNGRY-THE-LAST-DROP/` в конце.
- Сначала открой адрес игры обычным браузером. Если не открывается там, Mini App тоже пока не заработает.
- Если BotFather случайно показал токен, не отправляй его в переписку. При подозрении на утечку отзови его через @BotFather и выпусти новый.

Официальные инструкции: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [GitHub Pages](https://docs.github.com/en/pages), [установка Web App в Chrome на Android](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=ru), [добавление сайта на главный экран в Safari на iPhone](https://support.apple.com/ru-ru/guide/iphone/iph42ab2f3a7/ios).
