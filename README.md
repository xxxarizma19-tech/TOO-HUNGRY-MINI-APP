# TOO HUNGRY Mini App

Browser and Telegram Mini App build for XARIZMA19's TOO HUNGRY. The playable build is in site/; the development repository remains private.

Four kitchens retain their reduced 28 waves and NPC counts. Five bosses include the final BURGER TOO HUNGRY. Keyboard, touch and gamepad controls include a kick, healing pickups, music and sound effects. Boss progress and the final arena are saved locally.

GitHub Pages deployment is manual; pushing this repository does not publish the game.
