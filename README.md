# TOO HUNGRY Mini App

Browser and Telegram Mini App build for XARIZMA19's TOO HUNGRY. The playable build is in `site/`; the development repository remains private.

The build includes four kitchens with 28 enemy waves, four bosses, touch controls, keyboard/gamepad support, a kick ability, healing pickups, music, and sound effects. GitHub Pages deployment is manual; pushing this repository does not publish the game.
