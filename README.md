# TOO HUNGRY Mini App

Browser and Telegram Mini App build for XARIZMA19's TOO HUNGRY. The playable build is in site/; the development repository remains private.

Four kitchens contain 5, 6, 7 and 8 NPCs respectively, split into two encounters each. Five bosses include the final BURGER TOO HUNGRY. Keyboard, touch and gamepad controls include a kick, healing pickups, music and sound effects. Boss progress and the final arena are saved locally.

GitHub Pages deployment is manual; pushing this repository does not publish the game.

Each boss has three themed attacks: fries and hot oil; cheese thread and pizza boomerangs; nugget drops, cracks and crumb volleys; pasta tentacles, meatballs and noodle traps; patty drops, grill flames and pickle boomerangs. Bosses drop two 35% healing pickups at 67% and 34% HP. Collected drops persist across retries; uncollected drops return.
